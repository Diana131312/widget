# Сценарии оплаты

Бани и дома проходят оплату одинаково. Сертификат покупается отдельно: без счёта и без оплаты чужим сертификатом.

## Бани и дома

На оплате три варианта, если у организации включена оплата по счёту. Если нет — только частичная и полная.

- [ ] Промокод проверяется кнопкой «проверить». Непроверенный код в бронь не уходит.
- [ ] Принятый промокод уменьшает сумму к оплате. «Итого» остаётся полной стоимостью брони.
- [ ] Поле «Сертификат» есть только при частичной и полной оплате.
- [ ] Номер сертификата проверяется кнопкой «проверить».
- [ ] После проверки подсказка: «Электронный сертификат: спишется 3 000 ₽, останется 4 000 ₽».
- [ ] Нулевой остаток показывается, но к оплате не применяется.
- [ ] Пустые фамилия, имя, телефон или согласие не блокируют «Забронировать»: по нажатию поля красные, бронь не уходит.

### 1. Частичная оплата картой

- [ ] Гость выбирает частичную оплату и жмёт «Забронировать».
- [ ] Если телефон ещё не подтверждён, сначала код, потом бронь.
- [ ] Бронь создаётся с предоплатой.
- [ ] Гость сразу уходит на банковскую ссылку. Шаг ожидания не показывается.
- [ ] В расчёте: «Итого» — полная стоимость, «Предоплата» — исходная предоплата, «К оплате» — предоплата.

### 2. Полная оплата картой

- [ ] Гость выбирает полную оплату и жмёт «Забронировать».
- [ ] Бронь создаётся на полную стоимость.
- [ ] Гость сразу уходит на банковскую ссылку на всю сумму.
- [ ] В расчёте: «Итого» и «К оплате» — полная стоимость.

### 3. Сертификат закрывает всю сумму к оплате

- [ ] При частичной оплате списывается предоплата.
- [ ] При полной оплате списывается вся стоимость.
- [ ] Бронь создаётся, сертификат списывается сразу.
- [ ] Гость остаётся в виджете: «Заказ был успешно оплачен сертификатом».

### 4. Сертификата не хватает

- [ ] Бронь создаётся, с сертификата списывается сколько можно.
- [ ] Остаток гость сразу доплачивает по новой банковской ссылке.
- [ ] Строка сертификата жирная, отделена чертой и стоит перед «К оплате».
- [ ] «К оплате» — то, что осталось доплатить сейчас.

### 5. Сертификат введён, но не проверен

- [ ] «Забронировать» нажимается.
- [ ] Поле сертификата подсвечивается красным.
- [ ] Бронь не создаётся.

### 6. Сертификат не найден, не оплачен или просрочен

- [ ] Гость видит текст ошибки.
- [ ] Бронь не создаётся.

### 7. Бронь создалась, а списание сертификата не прошло

- [ ] Гость остаётся на шаге ожидания.
- [ ] Можно оплатить картой по исходной ссылке.

### 8. Банковской ссылки нет

- [ ] Гость остаётся в виджете.
- [ ] Текст: «Бронь создана».

### 9. Оплата с р/счёта юр. лица

- [ ] Вариант виден только если оплата по счёту включена.
- [ ] Поле «Сертификат» скрыто.
- [ ] Нужна почта «Почта для отправки счёта».
- [ ] Бронь создаётся на полную стоимость.
- [ ] Гость остаётся в виджете: «Ожидание выставления счёта» и обратный отсчёт.
- [ ] Гость указывает покупателя и ИНН, получает PDF и письмо.
- [ ] Пока счёт не выставлен, по окончании таймера бронь отменяется.
- [ ] После выставления счёта таймер бронь больше не отменяет. Оплату отмечает администратор.

## Сертификаты

Выбора оплаты нет: только обычная оплата. Счёта и поля «Сертификат» на покупке нет.

- [ ] Пустые поля покупателя не блокируют «Оплатить»: по нажатию они красные, заказ не уходит.
- [ ] Промокод проверяется кнопкой «проверить» на шаге покупателя. Непроверенный код не отправляется.
- [ ] Принятый промокод уменьшает сумму оплаты. Номинал сертификата остаётся полным.

### 1. Электронный

- [ ] На шаге покупателя обязательна «Почта для отправки сертификата».
- [ ] После «Оплатить» заказ сохраняется.
- [ ] Гость сразу переходит по ссылке на оплату.

### 2. Бумажный

- [ ] Почту гость не вводит.
- [ ] Заказ сохраняется и уходит на ссылку оплаты.

### 3. Заказ уже оплачен и ссылки нет

- [ ] Гость остаётся в виджете.
- [ ] Текст: «Заказ оплачен».

### 4. Ссылки на оплату нет и заказ не оплачен

- [ ] Оплата не открывается.
- [ ] Текст: «Не получили ссылку на оплату».
